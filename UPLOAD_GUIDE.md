# Upload guide

1. Open `https://github.com/ashh-droid/Portfolio`.
2. Choose **Add file → Upload files**.
3. Upload every file from inside this folder.
4. Commit with:
   `Refresh portfolio content and structure`
5. Open **Settings → Pages** and confirm:
   - Source: Deploy from a branch
   - Branch: `main`
   - Folder: `/ (root)`

The website address should be:

`https://ashh-droid.github.io/Portfolio/`

After deployment, test:

- Home navigation
- Project links
- Resume PDF
- Resume print button
- About page
- LinkedIn, GitHub, and email links
- Mobile menu

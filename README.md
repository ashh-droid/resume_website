## Deploy with GitHub Pages

1. Replace the files in `ashh-droid/resume_website` with this folder's files.
2. Commit and push the changes.
3. Open repository **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. The expected address will be:
   `https://ashh-droid.github.io/resume_website/`

The Wobb app update uses that expected Pages address for its Portfolio link.

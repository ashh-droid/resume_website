The challenge

Presenting complex industrial solutions through a clear, customer-focused experience.

Arcanelinx needed a modern website capable of explaining AI-enabled solutions, CNC and PLC automation, machine optimisation, retrofit services, and industrial engineering capabilities without overwhelming visitors.

What I built

A responsive corporate website with a practical enquiry journey.

01

Architecture and responsive UI

Designed the website structure and responsive interface for desktop, tablet, and mobile devices.

02

Guided quotation workflow

Implemented a guided quotation request flow with form validation and user-friendly navigation.

03

SEO and structured metadata

Integrated SEO metadata and structured data to support professional presentation and discoverability.

04

Business documentation

Added downloadable company profiles and legal information pages for business visitors.

05

Validated production delivery

Used GitHub version control, automated build validation through GitHub Actions, and Cloudflare deployment.

Technical decisions

Tools chosen for maintainability and deployment.

Next.js and TypeScript

Used a component-based application structure with typed development for maintainable page and feature work.

GitHub workflow

Used version control to manage changes and support production build validation.

Cloudflare delivery

Prepared and deployed the website using Cloudflare infrastructure.

What I learned

Translating real business requirements into reliable software delivery.

This project strengthened my experience in software engineering, responsive web development, production deployment, information architecture, and building digital solutions for a real business.

Hostel Allocation System

A role-based Django application for managing hostel requests, student records, room allocation, and administrative workflows, with Docker and Kubernetes deployment resources.

Problem

Bring hostel applications, records, and room allocation into one system.

Manual and disconnected steps make it difficult to track requests, room availability, and allocation status. The application centralises those workflows for students, wardens, and administrators.

User workflows

Different experiences for each role.

Sign in → Submit request → Review records → Allocate room → View result

Students

Apply for accommodation, track status, and view allocation details.

Wardens

Review requests and oversee student and room information.

Administrators

Manage users, records, allocation workflows, and system configuration.

Architecture

Django application with role-based access and structured data models.

The application uses Django authentication and ORM models for users, students, rooms, applications, and allocations.

Deployment

Package and run the application consistently.

Docker provides a repeatable application environment. Kubernetes resources manage deployment, service access, configuration, secrets, replicas, and application health checks.

Docker

Packages the Django application and dependencies in one consistent environment.

Kubernetes

Uses Deployments and Services to run and expose the application.

Reliability

Includes liveness checks, readiness checks, ConfigMaps, Secrets, and replica support.

Next steps

Improve production readiness.

The next improvements would include PostgreSQL, automated tests, CI/CD, cloud deployment, centralised monitoring, and stronger transaction handling for room allocation.

Hostel Allocation System

A web-based hostel management application that supports student applications, administrative review, room allocation, and deployment through Docker and Kubernetes.

The problem

Bringing hostel applications, records, and room allocation into one system.

The project replaces disconnected manual steps with a role-based application where students can apply and track their status while wardens and administrators review records and manage room allocation.

Application workflow

Separate experiences for students, wardens, and administrators.

Register or sign in → Submit hostel request → Review records → Allocate room → View allocation details

Student workflow

Registration, authentication, hostel applications, status tracking, and allocation details.

Warden workflow

Request review, student and room oversight, and operational record management.

Administrator workflow

User management, dashboards, allocation records, configuration, and system administration.

Application structure

Django-based application with clear domain entities.

The project uses Django ORM and separates core information into users, student profiles, hostel rooms, applications, and final allocations.

Deployment work

Moving the application beyond local development.

The application was containerised using Docker and prepared for Kubernetes deployment with Deployments, Services, configuration management, secrets, replicas, and application health monitoring.

Docker

Provides a consistent runtime environment for the Django application and its dependencies.

Kubernetes

Uses Deployments and Services for application orchestration and access.

Operational reliability

Includes liveness checks, readiness checks, ConfigMaps, Secrets, and replica support.

What I would improve next

Strengthening production readiness.

The next steps would include PostgreSQL, automated tests, CI/CD, cloud deployment, centralised monitoring, and stronger transaction handling for room allocation.
